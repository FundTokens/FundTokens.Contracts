# FundTokens Contracts

FundTokens lets anyone hold a trustless, self-custodial basket of Bitcoin Cash native
assets using CashTokens and smart contracts. No middlemen. Transparent rules. On-chain.

Deposit a fund's backing (BCH and CashTokens) to mint its fund tokens; return fund tokens
to redeem the backing. Fund definitions are fixed and published on-chain, the contracts are
non-upgradeable, and every fund token works anywhere CashTokens do.

## Repository

```
fund-tokens-contracts/            ← contracts and the @fundtokens/builders library
└── src/fund-types/<type>/<version>/
    ├── contracts/*.cash          ← CashScript sources, frozen once released
    ├── artifacts/                ← generated by yarn build:contracts
    ├── tests/
    └── *.ts                      ← that version's builders
docs/                             ← documentation, laid out by fund type and version
```

## Building and testing

```bash
cd fund-tokens-contracts
yarn install
yarn build:contracts   # after changing a .cash source
yarn verify            # artifacts current, type-check, all tests, build
```
